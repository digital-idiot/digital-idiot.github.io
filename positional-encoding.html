Positional Encoding: Teaching a ViT Where Patches Are

Seven encodings, from raster index to 2‑D RoPE
→→→→
1 of 7 · Order

A vision transformer sees a bag of patches

ViT cuts the image into patches and attends from every patch to every other. Nothing in \(QK^\top\) says where a patch was. Rearrange the patches and every output is the same, only rearranged.

\[ \text{Attn}(PX)=P\,\text{Attn}(X) \] \[ P:\ \text{any permutation of the patches} \]

Scramble the patches: the sun patch gets exactly the same output vector, wherever it lands. The two plain sky patches, and the two plain lawn patches, are indistinguishable too.

Hover a patch or a row to follow it across both images.

Turn the embedding on and the outputs split apart. So how should we write a patch's position into a vector? Start with the obvious: number the patches.

2 of 7 · Absolute

Number the patches, or learn a vector for each

Each patch position gets a vector \(p_{r,c}\), added to the patch embedding. Two obvious choices, two different failures.

\[ x_{r,c}=e_{r,c}+p_{r,c} \]

Click a patch on the image to probe it.

We want a code that is bounded, works at any resolution, and keeps neighbours close. Start with one axis: number the pixel columns in binary.

3 of 7 · Frequencies

Count in binary, then smooth the bits into waves

Take one axis of the image: pixel column \(t=0,1,2,\ldots\) In binary, the lowest bit flips every column, the next every 2 steps, the next every 4. Each bit is a square wave with its own frequency: a bounded code for any position.

\[ b_i(t)=\Big\lfloor \tfrac{t}{2^i}\Big\rfloor \bmod 2 \quad\text{period } 2^{i+1} \] \[ \text{smooth: } \sin(\omega_i t),\ \cos(\omega_i t),\quad \omega_i=\pi/2^i \]

Step with the buttons or the ← → keys. Watch the bits as you cross 7 → 8, 15 → 16 and 31 → 32.

Binary jumps: 31 → 32 flips six bits, so neighbouring columns can look far apart. Sines are smooth but still uneven. A sine + cosine pair is a point on a circle, and each step turns it by the same angle: every neighbour is the same distance away. That is the transformer's sinusoidal encoding.

4 of 7 · Sinusoidal

Sine and cosine at many frequencies

Use \(d/2\) clock hands, each turning at its own speed, from one turn every \(2\pi\) columns down to one every \(2\pi\cdot\text{base}\). For images, DETR and MAE encode a patch at \((x,y)\) as \([\,p_x,\ p_y\,]\): half the channels for the column, half for the row.

\[ p_{t,2i}=\sin(\omega_i t),\quad p_{t,2i+1}=\cos(\omega_i t) \] \[ \omega_i=\text{base}^{-2i/d} \]
The relative property\[ \begin{pmatrix}\sin\omega(t{+}k)\\ \cos\omega(t{+}k)\end{pmatrix}=R(\omega k)\begin{pmatrix}\sin\omega t\\ \cos\omega t\end{pmatrix} \] \[ R(\alpha)=\begin{pmatrix}\cos\alpha & \sin\alpha\\ -\sin\alpha & \cos\alpha\end{pmatrix} \] \[ p_t\cdot p_{t+k}=\textstyle\sum_i \cos(\omega_i k) \]

Moving by \(k\) turns every hand by a fixed angle, whatever \(t\) is. The similarity of two positions depends only on their distance. Next: the same trick for 2‑D coordinates.

5 of 7 · Fourier features

For space: plane waves in random directions

Images, maps and 3‑D scenes (NeRF) have continuous coordinates. Project the coordinate onto many frequency vectors \(b_j\) and take sine and cosine. Each feature is a plane wave across the space.

\[ \gamma(v)=\tfrac{1}{\sqrt m}\big[\cos 2\pi Bv,\ \sin 2\pi Bv\big] \] \[ \gamma(v)\cdot\gamma(u)=\tfrac1m\textstyle\sum_j\cos\big(2\pi\, b_j\cdot(v-u)\big) \]

The similarity depends only on \(v-u\): it is shift‑invariant again. \(\sigma\) sets how fine a detail the network can resolve. Next: Swin drops the vectors and puts 2‑D offsets directly into the attention scores.

6 of 7 · Relative

Swin: a learned bias for every 2‑D offset

Swin attends inside \(M\times M\) windows. Each head learns one small table \(\hat B\) holding a bias for each offset \((\Delta r,\Delta c)\). Every query reads the same table, shifted to sit on itself.

\[ \text{Attn}=\operatorname{softmax}\!\Big(\frac{QK^\top}{\sqrt d}+B\Big)V \] \[ B_{ij}=\hat B\big[\Delta r_{ij}+M-1,\ \Delta c_{ij}+M-1\big] \] \[ \hat B\in\mathbb{R}^{(2M-1)\times(2M-1)}\ \text{per head} \]

Click a patch in the window to make it the query. The four head tables are illustrative shapes; trained Swin heads show similar local, horizontal and vertical preferences.

In Swin's ablations this bias beat absolute embeddings on ImageNet, COCO and ADE20K. It only touches the scores, though. Next: put relative position inside \(q\cdot k\) itself, by rotating.

7 of 7 · RoPE

2‑D RoPE: rotate \(q\) and \(k\) by column and row

Rotary embeddings turn each 2‑D pair of \(q\) and \(k\) by an angle set by the patch position. Axial 2‑D RoPE uses half the pairs for the column \(x\), half for the row \(y\). A dot product only sees the angle between them, so only the offset survives.

\[ R(\alpha)=\begin{pmatrix}\cos\alpha&-\sin\alpha\\ \sin\alpha&\cos\alpha\end{pmatrix} \] \[ \tilde q=\begin{pmatrix}R(x\theta)&\\&R(y\theta)\end{pmatrix}q \] \[ \tilde q^{\top}\tilde k=q^{\top}\begin{pmatrix}R(\Delta x\,\theta)&\\&R(\Delta y\,\theta)\end{pmatrix}k \]

Query patch

Key patch (or click the map)

Heo et al. (2024) brought RoPE to ViTs; EVA‑02 and DINOv3 use it. A model trained at 224 px can run at 512 px: unseen positions are just larger angles, with no table to resize. Learnable, mixed frequencies (RoPE‑Mixed) also let a head attend along diagonals.
